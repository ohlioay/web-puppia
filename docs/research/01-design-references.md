# 01. 디자인 레퍼런스 13선

> 선정 기준: 사용자가 제시한 방향 — **심플 / 큼직한 볼드 타이포 / 간결 / 강한 이미지·영상 / 브랜드 컬러로 정제된 컬러웨이 / 단일 아이코닉 제품의 전문성**
> 각 항목은 `무엇을 훔칠 것인가` 한 줄로 요약된다.

---

## A. "단일 제품을 브랜드의 아이콘으로 만드는" 방식

### 1. Apple — iPhone 제품 페이지 (apple.com)
- **핵심**: 한 스크롤 = 한 메시지. 초대형 산세리프 헤드라인 + 흑배경 + 제품만 남기는 조명. 스펙을 나열하지 않고 **해부(anatomy)** 한다. 스크롤에 따라 제품이 회전·분해되는 시퀀스.
- **디테일**: 헤드라인은 문장이 아니라 **명사구**("Titanium. So strong. So light."). 여백이 정보량보다 크다.
- **훔칠 것**: 소프트하네스 페이지를 "제품 소개"가 아니라 **"제품 해부 다큐"** 로 만든다. `숨쉬는 메쉬 → 압력 분산 패턴 → 이중 잠금 버클 → 견종별 체형 대응` 4개 씬.

### 2. Rimowa
- **핵심**: 알루미늄 그루브라는 **단 하나의 형태 언어**를 40년째 반복. 화면의 절반 이상이 소재 극단 클로즈업. 컬러는 실버/블랙/티타늄으로 극히 제한.
- **훔칠 것**: 퍼피아의 "그루브"에 해당하는 형태 요소를 하나 정해서(예: 소프트하네스의 A자 등판 실루엣, 혹은 가슴 패드의 스티치 라인) **모든 페이지의 그래픽 모티프**로 반복 사용. 파비콘, 로딩 인디케이터, 섹션 디바이더까지.

### 3. Fjällräven Kånken / Herman Miller Aeron (아카이브형)
- **핵심**: 수십 년 된 단일 제품을 **연표·아카이브 페이지**로 운영. "1978년 출시 → 몇 세대 개량 → 현재"를 보여주는 것만으로 전문성이 증명된다.
- **훔칠 것**: `PUPPIA ARCHIVE` — 소프트하네스 세대별 변화(패턴 개선, 원단 변경, 컬러웨이 히스토리)를 가로 스크롤 타임라인으로. **신생 브랜드가 절대 복제할 수 없는 자산.**

## B. "기술·소재를 브랜드 언어로 만드는" 방식

### 4. Arc'teryx
- **핵심**: GORE-TEX·Coreloft 같은 소재명과 3D 패터닝을 브랜드 자산으로 승격. 제품 사진 옆에 **단면 다이어그램**을 나란히 놓는다. 컬러는 무채색 + 시그니처 1색.
- **훔칠 것**: 퍼피아 원단을 **네이밍**한다(예: `PUPPIA SoftMesh™`, `FlexFit Pattern™`). 이름이 붙는 순간 재질이 기술이 되고, 바이어 세일즈 토크의 재료가 된다. 사이트에는 원단 단면 일러스트 + 통기·신축 수치.

### 5. On Running (CloudTec)
- **핵심**: 기술의 **시각적 시그니처**(밑창의 구멍 모듈)를 제품 사진, 아이콘, 배경 패턴 어디서나 반복. 기술명이 곧 형태다.
- **훔칠 것**: 하네스 압력 분산 구조를 **히트맵 그래픽**으로 시각화. "목이 아닌 가슴으로 하중 분산" — 목줄 대비 압력 비교를 컬러 그라디언트로. 이 한 장이 소프트하네스의 존재 이유를 설명한다.

### 6. Bang & Olufsen
- **핵심**: 제품을 가전이 아니라 **오브제**로 촬영. 컬러/소재 스와치를 큼직한 원형 칩으로 보여주고 클릭 시 실물 텍스처가 바뀐다. 배경은 항상 톤다운.
- **훔칠 것**: 컬러웨이 셀렉터를 **패션 브랜드식 스와치 UI**로. 강아지 용품 사이트가 보통 썸네일 나열로 처리하는 부분을 이렇게만 바꿔도 격이 달라진다.

## C. "펫 카테고리 안에서의" 벤치마크

### 7. Wild One
- **핵심**: "강아지 브랜드계의 글로시에"로 불림. 파스텔 정제 팔레트, 로고 최소화, 제품을 **인테리어 소품처럼** 배치. Walk Kit(하네스+리드+배변봉투 케이스) 세트를 시그니처로 밀어붙임.
- **훔칠 것**: (a) **세트 판매의 시각화** — 퍼피아도 하네스+리드 컬러 매칭 세트를 하나의 "키트"로 묶어 대표 이미지화. (b) 강아지가 아니라 **제품이 주인공인 정물 컷**을 최소 1개 섹션에 배치. 펫 사이트 대부분이 강아지 사진만 쓴다 → 정물 컷이 오히려 차별점.

### 8. Ruffwear
- **핵심**: 퍼포먼스 펫기어의 표준. 필드 액션 사진 + 기능 콜아웃 다이어그램 + 상세한 사이즈 가이드(흉위 측정법)의 조합. 스토어 로케이터로 오프라인 딜러 연결.
- **훔칠 것**: 액션 사진 위에 **핀 형태의 기능 콜아웃**을 얹는 패턴. 그리고 사이즈 가이드를 페이지 하단 표가 아니라 **제품 페이지의 1급 콘텐츠**로 끌어올린다. (하네스 카테고리의 반품 사유 1위는 사이즈다.)

## D. "아트디렉션·몰입" 상한선

### 9. Gentle Monster
- **핵심**: 한국 브랜드가 글로벌 럭셔리 인식을 획득한 대표 사례. 제품보다 **아트 인스톨레이션과 필름**이 먼저 나온다. 웹에도 3D 시각화와 인터랙티브 요소를 적극 사용.
- **훔칠 것**: 시즌마다 사이트 첫 화면을 **캠페인 필름 1편**으로 완전히 교체하는 운영 구조. 사이트를 "제품 목록"이 아니라 **"발행물"** 로 다룬다.

### 10. Aesop (Work & Co 리뉴얼)
- **핵심**: 매장 경험을 그대로 옮긴 디지털 스토어프론트. 극단적 여백, 좁은 컬럼, 세리프 타이포, 애니메이션 거의 없음. **"움직이지 않는 것"으로 고급을 만든다.**
- **훔칠 것**: 사이트 전체를 화려하게 하지 말 것. 홈과 소프트하네스 페이지에만 모션을 몰아주고, About/Sustainability/Contact 같은 페이지는 **의도적으로 정적으로** 남긴다. 대비가 있어야 몰입 구간이 살아난다.

### 11. Nike (Air Max / SNKRS)
- **핵심**: 화면을 꽉 채우는 볼드 콘덴스드 타이포, 스크롤·호버에 반응하는 키네틱 텍스트, 시리즈 아카이브(에어맥스 계보).
- **훔칠 것**: 볼드 타이포 자체보다 **"시리즈 계보"** 개념. `SOFT HARNESS A / B / C` 라인을 나이키의 에어맥스 라인업처럼 계보도로 보여준다.

## E. 인터랙션 상한선 (기술적 야망의 기준점)

### 12. OFF+BRAND / Lusion / Active Theory 급 WebGL 사이트
- Awwwards 최상위권 사이트들(2025~2026 Site of the Year 후보군: OFF+BRAND의 Lando Norris 공식 사이트, WebGL 기반 인터랙티브 프로젝트들, Lusion의 가상 제품 런칭 페이지 등).
- **핵심**: 실시간 라이팅, 물리 기반 렌더링, 커서·스크롤·기울기에 반응하는 씬. 다만 **모두 폴백과 로딩 설계가 정교하다.**
- **훔칠 것**: 목표 수준의 상한선으로만 참조. 퍼피아가 이 수준을 전면 도입하면 유지보수·비용·성능이 무너진다. **"딱 두 곳에만 이 수준"** 이 현실적 답.
> ※ 수상 이력은 시점별로 갈리므로 최종 문서화 시 Awwwards 페이지에서 재확인 필요.

### 13. Mana Yerba Maté
- **핵심**: 캔 3D 렌더를 스크롤에 맞춰 회전·플립·이동시키며 홈 전체를 하나의 제품 서사로 만든다. 제품이 항상 화면 중심에서 벗어나지 않음.
- **훔칠 것**: **홈 히어로의 정답 패턴이 바로 이것.** 소프트하네스 1개 모델을 스크롤 전 구간에서 놓지 않고, 회전하며 각 기능 씬으로 이어붙인다.

## 디자인 시스템 합성 결론

| 요소 | 결정 |
|---|---|
| 타이포 | 헤드라인: 초대형 그로테스크 볼드 (Suit / Pretendard / Neue Haas Grotesk Display 계열). 한글·영문 동시 대응 필수. 본문: 동일 패밀리 Regular |
| 헤드라인 원칙 | 문장 금지, **명사구 3~5단어**. 한 화면에 헤드라인 1개 |
| 컬러 | 무채(오프화이트/차콜) 베이스 + **퍼피아 시그니처 1색** + 시즌 컬러웨이 스와치. 전면에 쓰는 색은 페이지당 2개 이하 |
| 이미지 | 액션 컷 : 정물 컷 = 1 : 1 로 강제. 정물 컷이 전문성을 만든다 |
| 모션 | 홈 + 소프트하네스 페이지에만 집중. 나머지는 페이드/슬라이드 수준 |
| 모티프 | 형태 요소 1개를 선정해 전 페이지 반복 (섹션 디바이더, 로더, 아이콘) |
