# 02. 기능 레퍼런스 15선

> 디자인과 분리하여, **"무엇이 작동하는가"** 관점의 사례. 각 항목에 카페24 환경에서의 구현 난이도(★1~5)를 표기.

---

## A. 제품을 이해시키는 인터랙션

### 1. Bellroy — 인터랙티브 제품 데모 (난이도 ★★☆☆☆)
- 지갑에 카드를 한 장씩 넣으면 두께가 실시간으로 변하는 애니메이션. "Slim Your Wallet" 페이지는 스크롤 인터랙션의 교과서로 반복 인용된다.
- **핵심 통찰**: 3D가 아니라 **미리 렌더링한 이미지 시퀀스**를 스크롤/슬라이더에 매핑한 것. 성능·호환성이 압도적으로 좋다.
- **퍼피아 적용**: **"핏 시뮬레이터"** — 슬라이더로 강아지 흉위(30cm→70cm)를 조절하면 하네스 조절 스트랩이 늘어나고 사이즈 라벨(S/M/L/XL)이 바뀐다. WebGL 없이 이미지 시퀀스만으로 구현 가능.

### 2. Apple — 스크롤 비디오 스크러빙 (난이도 ★★★☆☆)
- 스크롤 위치를 비디오/이미지 시퀀스의 프레임에 매핑. `GSAP ScrollTrigger` + `<canvas>` 로 구현이 표준화되어 있다.
- **퍼피아 적용**: 하네스가 360° 회전하며 분해되는 60~90프레임 시퀀스. WebP 프레임 프리로드로 3D보다 가볍게 같은 효과.
- **주의**: 모바일에서는 프레임 수를 절반으로 줄이고, 저사양 기기엔 정적 이미지 폴백.

### 3. Nike By You / 3D 제품 컨피규레이터 (난이도 ★★★★☆)
- WebGL(Three.js/Babylon.js) 기반 실시간 커스터마이즈. 자료에 따르면 3D 인터랙티브 요소가 있는 사이트는 **평균 참여도 +40%, 세션 시간 +27%** 수준의 차이를 보인다고 보고된다.
- **퍼피아 적용**: 소프트하네스 **컬러웨이 컨피규레이터**. 실제 SKU에 존재하는 컬러만 선택 가능하게 하고, 선택 결과를 그대로 장바구니/문의로 연결. 하나의 .glb에 머티리얼만 교체하므로 모델 1개로 전 컬러 커버 가능 → **자산 제작비가 가장 효율적인 3D 활용법.**

### 4. Bang & Olufsen Beosound Shape — 모듈 컨피규레이터 (난이도 ★★★★☆)
- 모듈형 스피커를 사용자가 조합해 배치. 조합 결과가 곧 주문 사양.
- **퍼피아 적용 (B2B)**: 바이어용 **"컬렉션 빌더"** — 하네스+리드+의류를 조합해 자기 매장용 라인업을 구성 → 그대로 발주서로 전환. B2C 재미 요소가 아니라 **B2B 업무 도구**로 쓸 때 가치가 크다.

### 5. AR — model-viewer / AR Quick Look / Scene Viewer (난이도 ★★★☆☆)
- Google `<model-viewer>` 웹 컴포넌트 한 줄로 iOS(USDZ) / Android(glTF+Scene Viewer) AR을 동시에 지원. 2026 기준 스마트폰 90% 이상이 어떤 형태로든 AR을 지원.
- 리서치 자료들은 AR 도입 시 **장바구니 담기 +20~35%**, 반품률 **22~40% 감소** 수준의 효과를 보고한다. (출처별 편차가 크므로 참고치로만.)
- **퍼피아 적용**: "내 강아지 옆에 실제 크기로 놓아보기". 사이즈 감을 잡게 해 **반품률과 CS 문의를 동시에 줄인다.** 하네스는 사이즈 반품이 가장 큰 카테고리라 ROI가 명확.

## B. 사이즈·핏 — 이 카테고리의 진짜 전환 병목

### 6. Ruffwear — 사이즈 가이드 & 스토어 로케이터 (난이도 ★★☆☆☆)
- 흉위(가슴둘레 가장 넓은 부위) 측정법을 그림과 함께 안내하고, 제품별 사이즈 차트 제공. 별도의 스토어 로케이터로 오프라인 딜러 연결.
- **퍼피아 적용**: 필수. 다만 아래 7번으로 한 단계 진화시킨다.

### 7. Warby Parker / Ray-Ban — 가상 착용(VTO)의 번안 (난이도 ★★★☆☆)
- 얼굴을 인식해 안경을 씌워보는 기능. 펫 제품에 얼굴 인식은 실효성이 낮다.
- **번안 방향**: 얼굴 인식 대신 **"핏 파인더 퀴즈"** — `견종 → 몸무게 → 흉위 → 목둘레 → 활동 성향` 5문항으로 사이즈·모델 추천. 견종별 프리셋(닥스훈트=긴 몸통, 프렌치불독=굵은 목, 이탈리안 그레이하운드=탈출 위험) 을 내장하면 정확도가 크게 올라간다.
- **이게 퍼피아의 킬러 기능이 되어야 하는 이유는 04-extra-ideas.md 1번 참조.**

### 8. 스마트폰 AR 줄자 (난이도 ★★★★☆)
- WebXR hit-test로 화면 상 두 점 사이 실측. 브라우저·기기 편차가 커서 **보조 기능**으로만.
- **퍼피아 적용**: 핏 파인더 안에 "줄자가 없어요" 버튼 → AR 측정 보조. 실패 시 즉시 "종이 끈으로 재는 법" 영상으로 폴백.

## C. B2B 바이어 포털 — 사이트의 수익 축

### 9. Faire / NuORDER / RepSpark / Shopify B2B (난이도 ★★★★☆)
리서치에서 도출된 **바이어 포털의 표준 기능 세트**:

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 승인제 로그인 | 신청 → 사업자 검증 → 승인 → 계정 발급 | P0 |
| 거래처별 차등 가격 | 계정마다 다른 도매가·할인율 노출 | P0 |
| 실시간 재고 | 품절/입고예정 표시 | P0 |
| 매트릭스 주문 그리드 | 컬러 × 사이즈 격자에 수량 직접 입력 (바이어가 가장 원하는 UI) | P0 |
| 디지털 라인시트 | 시즌 카탈로그 열람 + PDF/XLS 다운로드 | P0 |
| 재주문 (Reorder) | 지난 주문 그대로 다시 담기 | P1 |
| 프리북(Pre-book) | 다음 시즌 선주문 | P1 |
| MOQ / 인코텀즈 / 리드타임 표시 | 해외 바이어 필수 정보 | P0 |
| 주문 이력 & 상태 추적 | 접수→확정→출고→선적 | P1 |

- 자료의 요지: *"바이어는 쉬우면 더 자주 재주문한다. 로그인해서 재고 보고 2분 만에 발주할 수 있으면, 견적 메일 왕복이 사라진다."*
- **퍼피아 적용**: 카페24 PHP+MariaDB로 P0 세트만 먼저 구현. 화려할 필요 전혀 없다. **표가 빠르게 뜨고 수량 입력이 편하면 끝.**

### 10. 브랜드 자산 다운로드 센터 (DAM) (난이도 ★★☆☆☆)
- 바이어가 실무에서 매번 메일로 요청하는 것: 제품 사진 원본, 로고 AI/SVG, 스펙시트, 인증서, 화보, 영상.
- **퍼피아 적용**: `/partners/assets` — 시즌별·제품별 자산을 zip으로 원클릭 다운로드. 다운로드 로그를 남겨 **어떤 바이어가 어떤 제품에 관심 있는지** 파악 (영업 리드).
- **투입 대비 바이어 만족도가 가장 높은 기능. 반드시 P0.**

### 11. 문의 티켓 시스템 (난이도 ★★☆☆☆)
- 일반적인 "문의하기 폼 → 메일 발송"은 글로벌 운영에서 반드시 깨진다(스팸함, 담당자 부재, 이력 소실).
- **퍼피아 적용**: 폼 제출 시 **티켓번호 발급 + 상태 조회 페이지 + 자동 라우팅**.
  - 라우팅: `일반 소비자 CS` / `바이어·수출 문의` / `AS·품질` / `협업·마케팅` 4갈래
  - 바이어 문의는 국가·회사명·MOQ 규모 필드를 필수화 → 스팸 필터링 + 리드 스코어링
  - 포털 로그인 사용자는 **메일 대신 포털 내 메시지 스레드**로 (이력 보존)

### 12. 스토어/딜러 로케이터 (난이도 ★★★☆☆)
- Ruffwear 등 대부분의 유통 병행 브랜드가 운영. 지도 API + 국가/도시 필터.
- **퍼피아 적용**: 국가별 공식 디스트리뷰터 맵. **바이어에게 "우리 매장이 공식 딜러로 노출된다"는 것 자체가 계약 인센티브다.**

## D. 운영·기술 기반

### 13. 다국어 / 지역화 (난이도 ★★★☆☆)
- 기본 EN, 확장 KO/JA/DE/FR/ES. `hreflang` 태그 + 언어 스위처. 자동 리디렉션은 하지 말 것(구글 색인 문제 + 사용자 반감) — **배너로 제안만.**
- 통화·단위(cm/inch, kg/lb) 토글은 펫 제품에서 특히 중요.

### 14. WebGL 사이트의 SEO 대응 (난이도 ★★★☆☆)
- 리서치 요지: 캔버스 안의 내용은 색인되지 않는다. **3D 씬과 동일한 정보를 담은 실제 HTML 텍스트를 항상 병기**해야 한다.
- 정적 빌드(Astro/Vite SSG)로 HTML을 미리 생성 → 카페24에 업로드하면 이 문제가 구조적으로 해결된다.
- 제품 페이지에 `Product` / `Organization` / `FAQPage` JSON-LD 스키마 삽입.

### 15. 접근성·모션 안전 (난이도 ★★☆☆☆)
- `prefers-reduced-motion: reduce` 감지 시 스크롤 잭·패럴랙스·자동 회전 전면 비활성화 → 정적 레이아웃으로 대체.
- 사운드는 기본 OFF + 지속 노출되는 토글. 자동재생 영상은 `muted playsinline`.
- 3D 뷰어에 키보드 조작(방향키 회전) + `aria-label` 제공.
- 대비비 WCAG AA 이상 — 오프화이트 배경 위 연회색 텍스트는 감성적으로 매력적이지만 글로벌 접근성 기준에서 탈락한다.
