# 04. 추가 제안 — 요청하지 않았지만 강하게 권하는 아이디어

우선순위 순으로 정렬. ★는 임팩트, ♦는 구현 난이도.

---

## 1. ★★★★★ ♦♦♦ Puppia Fit Engine — B2C 기능을 B2B 자산으로 전환하는 구조

**표면**: 소비자가 `견종 → 몸무게 → 흉위 → 목둘레 → 활동성향`을 입력하면 모델·사이즈를 추천받는다.

**진짜 가치**: 이 입력 데이터가 쌓이면 퍼피아는 **아무도 갖지 못한 데이터셋**을 얻는다.
- 국가별 인기 견종 분포
- 견종별 실측 사이즈 분포 (같은 푸들이라도 한국/독일/미국이 다르다)
- 사이즈별 수요 비중 → **생산 계획의 근거**

**그리고 이걸 바이어에게 준다.** `/partners` 에서 *"귀사 지역의 지난 분기 사이즈 수요 리포트"* 를 제공하면, 퍼피아는 물건 파는 회사가 아니라 **바이어의 매입 의사결정을 돕는 파트너**가 된다. 이건 경쟁사가 복제하는 데 최소 2년이 걸리는 해자다.

> 단일 기능으로 B2C 전환율 · 반품률 · B2B 관계 · 생산 계획을 동시에 개선한다. **가장 먼저 만들어야 할 차별화 기능.**

---

## 2. ★★★★★ ♦♦ 정품 인증 시스템 (QR / 시리얼)

퍼피아처럼 글로벌 유통되는 한국 펫 브랜드가 반드시 겪는 문제: **카피 제품과 병행수입.**

- 제품 택에 QR/시리얼 → 스캔하면 `puppia.com/verify/{code}` 로 이동
- 정품이면: 정품 확인 + 해당 제품의 사이즈 가이드 + 세탁법 + 보증 등록
- 위조/중복이면: 경고 + 공식 딜러 안내

**부수 효과가 더 크다**
- 오프라인 구매자를 온라인 데이터베이스로 끌어온다 (이메일 수집)
- 어느 국가에서 위조가 도는지 실시간 파악
- 공식 딜러에게 "정품 인증 지원 브랜드"라는 세일즈 무기 제공
- 소비자에게 "관리되는 브랜드"라는 인상 → 전문성 신호

## 3. ★★★★☆ ♦♦ 견종별 랜딩 페이지 (SEO 최강수)

`/fit/dachshund`, `/fit/french-bulldog`, `/fit/italian-greyhound`, `/fit/pug` …

각 페이지에 그 견종의 체형 특징, 왜 일반 하네스가 안 맞는지, 퍼피아의 어떤 모델이 맞는지, 실착 사진, 사이즈 실측 데이터.

- **검색 유입이 폭발한다.** "닥스훈트 하네스", "french bulldog harness size" 같은 롱테일 키워드는 경쟁이 낮고 구매 의도가 극도로 높다.
- 3D·모션 없이 텍스트와 사진만으로 만든다 → 제작비 낮고 성능 좋다
- Fit Engine 데이터가 쌓이면 이 페이지들이 자동으로 정확해진다
- 30개 견종만 만들어도 사이트 전체 유입 구조가 바뀐다

> **화려한 3D보다 이게 트래픽에 미치는 영향이 훨씬 크다.** 예산 배분 시 반드시 고려.

## 4. ★★★★☆ ♦ 바이어 온보딩 퍼널의 재설계

대부분의 브랜드는 `문의하기` 폼 하나로 바이어를 받고 끝낸다. 이건 손실이다.

```
1. /partners 공개 티저 — 라인시트 일부, MOQ, 리드타임, 현재 유통 국가를 미리 공개
   → "이 브랜드와 거래할 만한가"를 스스로 판단하게 한다 (문의 품질 상승)
2. /partners/apply — 회사명 · 국가 · 취급 카테고리 · 예상 물량 · 기존 취급 브랜드
3. 자동 스코어링 — 국가/물량 기준으로 우선순위 태깅
4. 승인 메일 = 계정 발급 + 첫 로그인 가이드 영상
5. 첫 로그인 시 온보딩 투어 (매트릭스 주문 방법 90초)
```

**핵심**: 3단계의 자동 스코어링. 문의가 늘어날수록 이게 없으면 대응이 무너진다.

## 5. ★★★★☆ ♦♦ 시즌 컬러 카드를 브랜드 자산으로

패션 브랜드가 시즌마다 컬러 팔레트를 발표하듯, 퍼피아도 시즌 컬러웨이에 **이름을 붙이고 카드로 발행**한다.

- `PUPPIA SS26 PALETTE` — 컬러명, HEX, 실물 원단 스와치 사진
- 다운로드 가능한 컬러 카드 PDF → 바이어의 매장 VMD 자료가 된다
- 사이트 홈 씬 4와 연결

컬러웨이가 "제품 옵션"에서 **"브랜드가 매 시즌 발표하는 것"** 으로 승격된다. 전문성 신호로 비용 대비 효과가 매우 크다.

---

## 6. ★★★☆☆ ♦♦ 실착 UGC 갤러리 `#PuppiaFit`

- 견종·사이즈·컬러로 필터되는 실착 사진 그리드
- 소비자가 업로드 시 견종/사이즈를 함께 입력 → **다른 소비자의 사이즈 판단 근거**가 된다
- 즉 UGC가 감성 콘텐츠가 아니라 **사이즈 판단 도구**로 기능한다 (이게 차별점)
- 제품 상세 페이지에 "같은 견종의 실착 12건" 모듈로 삽입

---

## 7. ★★★☆☆ ♦ "사이트를 발행물로 운영하기"

Gentle Monster 방식. 시즌마다 홈 첫 화면을 캠페인 필름으로 통째 교체하고, 이전 시즌은 `/stories` 아카이브로 이관.

- 사이트가 "만들고 끝"이 아니라 **살아있는 채널**이 된다
- 재방문 이유가 생긴다
- 운영 부담을 줄이려면 **교체 가능한 슬롯을 CMS화**해두어야 한다 (씬 7만 교체 가능하게 설계)

---

## 8. ★★★☆☆ ♦♦ 하네스 착용 튜토리얼 (인터랙티브)

의외로 큰 CS 원인: **하네스를 잘못 채운다.**

- 3~4단계 인터랙티브 가이드 (스텝별 GIF/짧은 루프 영상)
- "손가락 두 개가 들어가는 정도" 같은 검증 체크포인트
- QR(2번 아이디어)로 진입 가능하게
- 다국어 자막

CS 문의 감소 + 브랜드 신뢰 + 제품 만족도(잘 채운 하네스는 훨씬 편하다) 3중 효과.

---

## 9. ★★☆☆☆ ♦♦ 사운드 디자인

Awwwards 상위권 사이트의 공통점. 스크롤·호버·버클 잠금 시 미세한 사운드.

- **버클 "찰칵" 사운드**를 브랜드 사운드 시그니처로 (제품의 실제 소리)
- 기본 OFF, 우측 상단 토글 상시 노출
- 저비용·고인상 요소지만 **켜졌을 때 거슬리면 역효과** — 볼륨과 빈도를 극도로 절제

---

## 10. ★★☆☆☆ ♦ 다크모드 대신 "쇼룸 모드"

일반적인 다크모드가 아니라, 제품을 검은 배경 위에 놓는 **감상 모드**를 제품 상세에 토글로 제공.
Bang & Olufsen / Apple의 제품 사진이 검은 배경에서 극적으로 보이는 원리를 사용자가 직접 켤 수 있게.

---

## 11. ★★☆☆☆ ♦♦♦ 지속가능성 페이지의 실증화

"친환경 소재 사용"이라고 쓰는 브랜드는 수천 개다. 차이를 만드는 건 **숫자와 인증서**다.
- 리사이클 폴리에스터 함량 %, GRS/OEKO-TEX 인증 스캔본
- 자체 생산 시설이 있다면 그 자체가 강력한 자산 → 공장 촬영 화보
- 유럽 바이어는 이 페이지를 실제로 본다. **B2B 계약에 직접 영향.**

## 12. 예산이 부족하다면 — 잘라내는 순서

역설적이지만 명시해둔다. 예산 압박이 오면 이 순서로 자른다.

| 순위 | 항목 | 판단 |
|---|---|---|
| 먼저 자름 | 3D 컨피규레이터 | 이미지 시퀀스로 90% 대체 가능 |
| | AR | 있으면 좋지만 없어도 브랜드 인식엔 영향 없음 |
| | 사운드 디자인 | 취향 리스크 |
| | 홈 히어로 3D | 잘 만든 스틸 화보 + 키네틱 타이포가 못 만든 3D보다 낫다 |
| **절대 못 자름** | 큼직한 볼드 타이포 + 컬러 시스템 | 이게 전부다 |
| | 고품질 화보 (액션 + 정물) | **사진이 나쁘면 어떤 기술로도 커버 불가** |
| | 소프트하네스 Anatomy 페이지 | 전문성의 유일한 증거 |
| | 사이즈 가이드 / 핏 파인더 | 전환의 병목 |
| | 바이어 포털 P0 세트 | 수익 축 |

> **가장 중요한 조언: 웹 개발비보다 화보 촬영·3D 모델링 등 "콘텐츠 제작비"를 먼저 확보하라.**
> 이런 유형의 사이트는 코드가 아니라 **에셋의 품질**이 결과를 결정한다. 애플 사이트가 대단한 건 코드가 아니라 그 안의 이미지가 대단하기 때문이다.
