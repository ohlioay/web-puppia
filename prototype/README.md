# Scroll Prototype 01 — Soft Harness

`docs/research/03-strategy.md`의 **홈 스크롤 시나리오**를 실제로 움직이는 코드로 옮긴 검증용 프로토타입.

```
prototype/index.html    단일 파일. 빌드 불필요. 브라우저에서 바로 열면 동작.
```

## 목적

이 파일은 **디자인 시안이 아니라 스크롤 연출·인터랙션의 타당성 검증용**이다.
확인하려는 것은 세 가지다.

1. 스크롤 한 번으로 "왜 소프트하네스인가"가 설명되는가
2. 3D 없이 어디까지 갈 수 있는가 (성능 예산 검증)
3. 핏 시뮬레이터 같은 인터랙션이 실제로 이해되는가

**모든 도형은 플레이스홀더다.** 제품 사진·3D 모델·화보가 들어갈 자리를 SVG 라인아트로 대신 채웠다.
실제 자산으로 교체할 때 레이아웃과 스크롤 타이밍은 그대로 재사용할 수 있다.

## 구현된 씬

| # | 씬 | 인터랙션 | 상태 |
|---|---|---|---|
| 0 | 로더 | 라인 드로잉 + 진행률 | 동작 |
| 1 | 히어로 | 커서 추적 회전, 스크롤 이탈 | 동작 |
| 2 | 압력 비교 | 스크롤 진행률 → 목줄 히트맵 확대 → 하네스 분산 플레이트 등장, 수치 실시간 갱신 | 동작 |
| 3 | 해부 | 스크롤 진행률 → 4개 레이어 분리, 해당 스펙 행 하이라이트 | 동작 |
| 4 | 컬러웨이 | 스와치 클릭 → 제품 컬러 실시간 변경 (CSS 변수 1개) | 동작 |
| 5 | 핏 시뮬레이터 | 흉위 슬라이더 → 강아지 스케일 · 사이즈 배지 · 표 행 · 견종 추천 동시 갱신 | 동작 |
| 6 | 견종 인덱스 | 체형 필터 칩 + 드래그 가로 스크롤 | 동작 |
| 7 | CTA | — | 정적 |
| 8 | 유통 국가 | 도트 호버 → 국가명 | 동작 |

## 기술 메모

- **외부 라이브러리 0개.** GSAP·Lenis·Three.js 없이 바닐라 JS + `requestAnimationFrame` 스로틀 스크롤로 구현했다.
  실제 구축 시 GSAP ScrollTrigger를 쓰면 코드가 짧아지지만, **이 정도 연출은 라이브러리 없이도 가능하다**는 것이 확인됐다.
- **핀 방식**: `.scene { height: N vh }` + `.pin { position: sticky }`. 스크롤 잭 없이 네이티브 스크롤을 유지한다.
- **씬 진행률**은 `--p` CSS 변수(0→1)로 내려보내고, CSS `calc()`와 JS가 각각 필요한 만큼만 읽는다.
- **컬러웨이**는 `--product` 변수 하나만 바꾼다. 실제 사이트에서 3D 머티리얼 교체로 대체될 지점.
- **`prefers-reduced-motion: reduce`** 시 모든 핀이 해제되고 각 씬이 최종 상태의 정적 레이아웃으로 렌더된다
  (문서 길이 12,284px → 7,334px). 정보 손실 없음.
- 390 / 768 / 1440px에서 가로 오버플로 0, 콘솔 에러 0으로 확인.

## 컬러 시스템

제품의 핵심 논리(압력 분산)를 그대로 색으로 쓴다. 장식이 아니라 의미다.

| 토큰 | 값 | 의미 |
|---|---|---|
| `--load` | `#2A45E0` | 분산된 하중 = 하네스 |
| `--press` | `#E1492A` | 집중된 압박 = 목줄 |
| `--ink` | `#14171B` | 쿨 니어블랙 그라운드 |
| `--bone` | `#E9E8E1` | 쿨 본 페이퍼 그라운드 |

씬이 본↔잉크 그라운드를 번갈아 밟는 구조라 **단일 비주얼 월드로 고정**했다(테마 전환 없음, 모든 색 명시).
내비게이션은 현재 씬의 그라운드를 감지해 색과 배경을 전환한다.

## 타이포

| 역할 | 서체 |
|---|---|
| 디스플레이 | Archivo 900 / width 118% |
| 본문 | Instrument Sans |
